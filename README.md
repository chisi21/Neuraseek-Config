## ⚙️ Installation & Setup

To run the NeuraSeek assistant locally or integrate the API, follow these steps:

1. **Clone the Repository**
```bash
git clone https://github.com/yourusername/neuraseek.git
cd neuraseek

```


2. **Install Dependencies**
```bash
npm install # for the frontend/bot
# or
pip install -r requirements.txt # for the AI engine

```


3. **Environment Configuration**
Create a `.env` file in the root directory:
```env
SOLANA_RPC_URL=https://api.mainnet-beta.solana.com
OPENAI_API_KEY=your_key_here
HELIUS_API_KEY=your_key_here

```


4. **Launch Application**
```bash
npm run start

```
